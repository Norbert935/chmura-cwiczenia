
# Słownik usług chmurowych

Poniższa tabela przedstawia pięć rodzajów usług chmurowych oferowanych przez AWS, Microsoft Azure oraz Google Cloud.

| Rodzaj usługi | AWS | Microsoft Azure | Google Cloud |
|---|---|---|---|
| Maszyny wirtualne | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Przechowywanie obiektów | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Funkcje bezserwerowe | AWS Lambda | Azure Functions | Cloud Run functions |
| Relacyjne bazy danych | Amazon RDS | Azure SQL Database | Cloud SQL |
| Kontenery Kubernetes | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

Poszczególni dostawcy oferują podobne rodzaje usług, które różnią się nazwami, sposobem konfiguracji oraz możliwościami.
