
# Bezpieczeństwo repozytorium GitHub

W publicznym repozytorium nie wolno zapisywać haseł ani kluczy dostępu, ponieważ mogą zostać odczytane i wykorzystane przez nieuprawnione osoby.

Samo usunięcie pliku nie wystarcza, ponieważ Git przechowuje historię zmian, w której wcześniejsze wersje plików nadal mogą być dostępne.

Każdy, kto ma dostęp do historii repozytorium, może potencjalnie odnaleźć wcześniej zapisane hasło lub klucz.

W przypadku ujawnienia takich informacji należy natychmiast zmienić hasło lub unieważnić klucz, a następnie usunąć poufne dane również z historii repozytorium.
